
# GREEN EARTH 🌍

## Environmental Awareness Website

Green Earth is a website that promotes environmental
protection and encourages people to take care of our planet.

### Website Pages

1. Home - Introduction to environmental awareness.
2. About - Mission, vision, and importance of protecting nature.
3. Gallery - Pictures showing the beauty of nature.

### Technologies Used

- HTML5
- CSS3

### Features

- Responsive website design
- Navigation links
- Nature pictures
- CSS hover effects
- Environmental information

### Purpose

To encourage everyone to protect the environment
and create a cleaner and greener future.
